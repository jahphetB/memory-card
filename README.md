# Memory Card

https://memory-card-eta-nine.vercel.app/

A React memory card game built as part of The Odin Project. Click each GIF only once while the cards shuffle after every selection.

## Features

- GIFs fetched from the GIPHY API
- Randomized card order
- Current score tracking
- Best score tracking
- Responsive layout
- Loading and error handling

## Built With

- React
- Vite
- JavaScript
- CSS
- GIPHY API
- Vercel

## Run Locally

```bash
npm install
npm run dev
